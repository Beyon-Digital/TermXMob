## Product and architecture

One durable Main agent is the default conversation for each owner. It retains an explicit local workspace context and delegates to authorized project children or existing engine sessions. Existing Internal, Codex, Claude and ACP conversations retain their identities and remain directly accessible. Projects, files, diffs and browser panels are contextual work surfaces.

The Python coordinator persists parent/child links, ownership, request receipts, source-labelled events, report delivery cursors and cancellation state. Delegation is bounded by existing tree limits. Explicit user takeover prevents conflicting orchestrator turns; returning ownership does not itself start work. Deferred reports can arrive after Main finishes without a background model request. Natural-language consolidation uses an explicit running Main turn, not an autonomous inference loop.

## Explicit limits

Inference is scripted and no-network. Authentication, HTTP/GraphQL, SQLite, tool execution, approvals, runtime, production React and process recovery are real. The native browser fixture exercises the normalized Python EngineAdapter/Gateway boundary; it does not run an ACP wire server or Codex/Claude vendor process. Protocol adapter regressions do not establish live vendor success.

Live vendor login/inference, subscription entitlement, native credential stores, installed Tauri behavior, other physical platforms and guest website navigation remain untested. ACP session-only chunks have no turn ID; captured host generations cannot guarantee cross-turn attribution for such protocol content. Native engine token usage and cost remain unmeasured and uncapped by TermX. Idle reports are durable source-labelled updates; automatic idle model synthesis is not claimed. The installed application and original user configuration were not replaced.
