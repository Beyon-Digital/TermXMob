Software Update now shows installed and available versions, release notes,
download progress, signature verification, installation status, and retryable
errors. Download, install, and restart are explicit actions. Closing the update
window preserves the current operation; reopen Check for Updates to return.

This release also fixes first-run native owner setup, native control-plane
navigation, and conversation navigation in short or zoomed desktop windows.
Detached windows restore their placement without crashing the Linux app, and
returning a saved draft no longer falsely conflicts with the main window.
Genuinely unsaved edits remain protected. Browser setup still requires the
host's bootstrap credential.

Installers include the Python backend and workspace runtime. macOS downloads are
available for Apple Silicon and Intel; Windows offers MSI and EXE installers;
Linux offers DEB, RPM, and AppImage packages. Save your work before installing or
restarting. Platform checksum files accompany the downloads.
