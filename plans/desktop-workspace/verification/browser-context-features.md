# Browser context, diagnostics and scoped tab commands

The production host/browser UI supports comments attached to an exact visible element or finite viewport region. Each record preserves its document revision, main-frame/viewport reference and element fingerprint or region. Explicitly opted-in masked JPEG references are served through owner/current-policy checks. Form fields, editable content and marked private regions are masked across frames; other page content can still be personal, so images require review before attachment. Private login blocks observation, comments, diagnostic data and annotation-image retrieval.

The user can compare the current target with the frozen original, capture a separately approved masked after image, resolve or reopen a comment, and inspect both exact references. Matching a selector after navigation does not establish that it is the same element; a different page makes the target unavailable. Navigation marks saved references stale. Only unresolved, current comments enter attached structured conversation context, which grants no browser control. Profile-scoped history deletion preserves cookies. Temporary profiles and their captures/transfers/history are removed on graceful shutdown and abrupt restart.

Developer observation requires explicit, expiring current-session consent and is cleared by takeover/private mode/policy changes. The inspector exposes actual sanitized DOM, console, network and performance data; stale responses cannot overwrite the selected tab/view. New/close/reopen keyboard commands require the focused browser surface or an explicitly targeted palette action. Remote page input consumes workspace chords, and Escape restores page controls.

The agent receives six broker tools: browser_tabs, browser_observe, browser_action, browser_open_tab, browser_close_tab and browser_wait_for_handoff. Lifecycle actions require explicitly selected grant permissions. A created child inherits exactly the parent task, identity, project, profile, approved origins/actions and no longer expiry. Closing a tab is human reviewed, consumes its permit once, and does not replay an uncertain effect. Main-frame semantic references are supported; this does not claim a recursive cross-frame semantic tree.
