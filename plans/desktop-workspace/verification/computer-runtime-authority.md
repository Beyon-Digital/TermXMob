# Computer authority, privacy intervals and recovery

The shared production Computer surface starts in watch-only mode. Control becomes available only after the host acknowledges a currently authorized control request. A denial clears local control state and presents its reason. Tab leaves the input canvas without sending a remote Tab; Escape restores the Return to watch control without sending a remote Escape. Separate Send Tab/Send Escape buttons preserve access to those actual remote keys. Closing a watch-only connection does not release another controller's keys. Global status distinguishes watching, control, agent tabs, private mode and recording, with reachable Open, Stop and browser takeover actions outside the active layout.

Private browser and window captures share one host observation barrier. Private input, DOM, screenshots and recordings do not reach either model. Entering and then leaving private mode while a Computer frame or multi-step input is in flight changes the privacy epoch; the stale frame/remaining subeffects are refused. Cleanup releases held keys even during private mode. A second valid human browser viewer cannot release the barrier by revoking the initiating session.

Window consent expiry or session revocation stops execution and new preview capture but retains its private observation pause while another human window can still display already-served pixels. Abrupt restart reconstructs that pause without reviving control. A fresh authorized owner sees only private/expired metadata and an explicit Stop capture recovery action; no title, image, typed value or session ID enters the status API. Stop releases the barrier. This can deliberately keep models paused until the owner performs recovery.

Shutdown stops internal workers and native engines before private ports/barriers close and while callback stores remain live. Internal close failure, timeout or remaining worker aborts barrier release. Strict native shutdown drains reader/turn tasks, rejects failed transports or a still-live subprocess, and retains failed session state for retry. The legacy best-effort cleanup helper is not used to declare secure worker termination. Actual native close fixtures remain distinct from installed product qualification.
