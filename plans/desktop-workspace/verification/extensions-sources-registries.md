# Native skill sources and HTTPS registry contract

The Extensions manager connects native source discovery/editing to explicit immutable bundle publication. Global sources require host administration; project sources require a canonical enrolled project and live file scopes. Source walks refuse symlinks/junctions, unsafe Markdown, embedded secrets and oversized files. Compare-and-save digest conflicts retain the unsent draft. Immutable versions restore as drafts; importing or saving source never enables execution.

Supported registry adapters are `private_local`, `public_https` and `private_https`. HTTPS uses the bounded `termx-registry/v1` JSON catalog and existing inert compatibility bundles. TLS certificate/hostname verification is required. Requests pin validated public resolved addresses, prohibit credential-bearing URLs and protected networks, and admit only bounded same-origin redirects/downloads. DNS lookup waits are bounded to three seconds, with at most four outstanding resolver workers; saturation or timeout refuses retrieval. Private Bearer credentials stay in the host credential store; UI fields are write-only. Credential rotation invalidates outstanding package reviews.

Downloaded raw SHA-256, canonical manifest hash, exact dependency versions/digests, provenance and added/removed permissions remain inspectable before explicit installation. Dependencies are never silently installed. Runtime activation freezes the exact dependency graph under existing use leases; missing or changed dependencies prevent dispatch. Live owner and project authority are rechecked after network retrieval and immediately before publication.

The test TLS resolver and test CA are trusted host composition hooks only. They are not exposed to HTTP clients or accepted from registry fields. Controlled loopback TLS fixtures exercise real socket/TLS/download behavior with no external sites, paid inference or OS credential writes. These fixtures do not establish availability of any external production registry or support for undocumented protocols/authentication formats.
